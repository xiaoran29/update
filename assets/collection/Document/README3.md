# 直播源聚合处理工具 v2.00（LiveSource-Collector）

> 一键抓取、清洗、分类、去重、输出「央视-卫视-地方台-港澳台-体育赛事」等 60+ 频道组，生成 TXT / M3U / HTML 三格式通用播放列表。

---

## 1. 功能总览
| 模块 | 说明 |
|---|---|
| **聚合** | 自动读取 `urls-daily.txt` 内所有订阅源（支持 `{MMdd}` 变量） |
| **清洗** | 去广告、去尾巴参数、繁→简、名称标准化、LOGO 补全 |
| **分类** | 60+ 频道组（央视/卫视/31 省级/港澳台/体育/影视/数字/收音机等） |
| **去重** | 全局 URL 集合 + 黑名单双保险，重复率一目了然 |
| **白名单** | 响应时间 < 2 s 的频道优先入库 |
| **手工区** | 本地高质源强制置顶，可叠加不冲突 |
| **输出** | 同时生成「完整版 / 精简版 / 定制版」×「TXT / M3U」+ 体育赛事独立 HTML |
| **时区** | 全程采用北京时间，日志与版本号统一 |
