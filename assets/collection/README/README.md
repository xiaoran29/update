IPTV直播源聚合处理工具

🎬 项目简介

一个高效、稳定的IPTV直播源聚合处理工具，能够从多个在线源收集、整理、分类和过滤直播源，生成多种格式的播放列表。

✨ 主要功能

· 多源聚合：从多个在线直播源网站聚合频道数据
· 智能分类：自动将频道按地区、类型、内容分类（63个分类）
· 格式转换：支持M3U格式自动转换为TXT格式
· 去重过滤：自动去除重复频道和黑名单频道
· 质量筛选：根据响应时间筛选高质量直播源
· 多格式输出：生成TXT、M3U、HTML等多种格式
· 频道名称规范化：自动清理频道名称，繁体转简体
· 日期变量支持：自动处理动态日期URL
· Logo支持：为频道自动匹配Logo图标

🔄 分类逻辑

优先级顺序

1. 央视频道 → 2. 卫视频道 → 3. 地方频道 → 4. 港澳台频道
2. 体育赛事 → 6. 专业频道 → 7. 综合频道 → 8. 直播平台
3. 其他频道（兜底分类）

去重原则

· 跨分类去重：同一URL不会出现在多个分类
· 质量优先：响应时间短的源优先保留
· 名称标准化：频道名称统一清理和格式化

🚀 快速开始

环境要求

· Python 3.7+
· 依赖包：opencc-python-reimplemented

安装依赖

```bash
pip install opencc-python-reimplemented
```

配置说明

1. 数据源配置：在 assets/livesource/urls-daily.txt 中添加直播源URL
2. 频道字典：在 assets/livesource/主频道/ 和 assets/livesource/地方台/ 配置频道字典
3. 黑白名单：在 assets/livesource/blacklist/ 配置过滤规则
4. 手工源：在 assets/livesource/手工区/ 添加高质量手工源

运行程序

```bash
# 运行v0.01版本
python livesource_collector.py

# 运行v0.02版本  
python main_v0.02.py

# 运行v0.04版本

```
