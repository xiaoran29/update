IPTV直播源聚合处理工具

一个功能强大的直播源聚合处理工具，支持多源采集、自动分类、去重过滤和多种格式输出。

📋 项目简介

这是一个Python编写的直播源处理工具，能够从多个数据源自动采集、整理和分类直播源，生成适用于各种播放器的播放列表文件。

✨ 主要特性

核心功能

· 多源聚合：支持从多个URL源自动采集直播源
· 智能分类：自动识别并分类63个频道类别（央视、卫视、地方台、体育赛事等）
· 去重过滤：全局URL去重机制，去除重复源和黑名单源
· 格式转换：支持M3U/TXT格式互转，自动生成带Logo的M3U文件
· 时间处理：自动处理日期变量，支持动态URL

数据处理

· 名称规范：自动清理频道名称，繁体转简体，统一CCTV/卫视格式
· 纠错系统：内置频道名称纠错字典
· 黑白名单：支持黑白名单过滤，确保源质量
· 手工源补充：支持手工区高质量源补充

输出格式

· 完整版：包含所有分类的完整播放列表
· 精简版：仅包含央视和卫视核心频道
· 定制版：不含地方台的其他所有分类
· 体育赛事：独立的体育赛事网页和文本文件
· M3U格式：自动生成带EPG和Logo的M3U文件

🚀 快速开始

环境要求

· Python 3.6+
· 依赖包：opencc

安装步骤

1. 克隆项目：

```bash
git clone https://github.com/yourusername/livesource-collector.git
cd livesource-collector
```

1. 安装依赖：

```bash
pip install opencc
```

1. 配置数据源：
   编辑assets/livesource/urls-daily.txt 添加直播源URL
2. 运行程序：

```bash
python livesource.py
```

项目结构

```
项目目录/
├── assets/
│   └── livesource/
│       ├── 主频道/          # 核心频道分类字典
│       ├── 地方台/          # 省级地方台字典
│       ├── 手工区/          # 高质量手工源
│       ├── blacklist/       # 黑白名单管理
│       └── corrections_name.txt  # 频道名称纠错
├── output/                # 输出目录（自动创建）
└── livesource.py         # 主程序
```

📁 输出文件

运行后会在 output/ 目录生成以下文件：

文件名 说明
full.txt 完整播放列表（所有分类）
full.m3u M3U格式完整版
lite.txt 精简版（央视+卫视）
lite.m3u M3U格式精简版
custom.txt 定制版（不含地方台）
custom.m3u M3U格式定制版
others.txt 未分类频道列表
tiyu.html 体育赛事网页版
tiyu.txt 体育赛事文本版
statistics.json 统计信息（v3.01）

🔧 配置说明

数据源配置

· URL列表：assets/livesource/urls-daily.txt
· 支持动态日期变量：{MMdd} 和 {MMdd-1}
· 示例：http://example.com/live_{MMdd}.txt

频道字典

· 主频道：央视、卫视等核心频道分类
· 地方台：33个省级行政区分类
· 内容分类：电影、电视剧、体育等22个分类
· 特殊分类：港澳台、体育赛事等

黑白名单

· 黑名单：自动黑名单（失效源）+ 手动黑名单（垃圾源）
· 白名单：高响应质量源，响应时间<2秒

🎯 使用示例

基本使用

```bash
# 运行主程序
python livesource.py

# 查看输出
ls output/
```

自定义配置

1. 添加数据源：编辑 assets/livesource/urls-daily.txt
2. 更新频道字典：编辑对应分类的TXT文件
3. 管理黑白名单：编辑 blacklist/ 目录下的文件
4. 添加Logo：编辑 logo.txt 文件

体育赛事

体育赛事会生成独立的网页文件，可以在浏览器中直接打开：

```bash
open output/tiyu.html
```
